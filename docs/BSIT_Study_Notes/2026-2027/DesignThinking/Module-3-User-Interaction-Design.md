## 1. User Interaction

- This is the users exchange of actions with a solution
- Exchange of actions are composed of physical and emotional aspects that are triggered by the solution's display, user's input and solution's feedback.
### 1.1 User Interaction Design 

- The ==design of interaction== between the user and the solution
- The ==creation of communication== between the user and the solution 
- The process of making an assurance that the user and the solution understands each other

### 1.2 UI and UX Design 

- User Interaction Design and User Experience are not the same 
- User Interaction Design is a part of User Experience Design 

### 1.3 UI Designer

- UI designer focus on the way users interact with products and they use principles of good communication to create desired user experiences. 


## 2.Five major characteristics of Interaction Design 

1. It changes situations by shaping and deploying artifacts.    
2. It explores possible futures.    
3. It frames the problem in parallel with possible solutions.   
4. It requires thinking through "sketching" and other "tangible representations".   
5. It addresses instrumental , technical, aesthetic and ethical aspects throughout the process.

## 4. Important Questions Interaction Designers Ask 

  

1. What can a user do with their mouse,finger, or stylus to directly interact with the interface. ??
   
	This helps designer define the possible user interactions with the product.

  

2. What about the appearance(Color, shape, size, etc)gives the user a clue about how it may function ?

	  This helps designer give users clues about what behaviors are possible .

  

3. Do error messagers provide a way for the user to correct the problrm or explain wht the error occurred?

	  This lets designer anticipate and mitigate errors

  

4. What feedback does a user get once an action is performed?

	  This allows designer to ensure that the system provides feedback in a reasonable time after user actions.

  

5. Are the interface elements a resonable size to interact with?

	  Questions like this helps us think strategically about each element used in the product.

  

6. Are familiar or standard formats used?

	  Standard elements and formats are used to simplify and enhance the learnability of a product .

  
  

## Best Practices in UI Design

  

- Keep the interface simple

- Create consistency and use common UI elements

- Be purposeful in page layout

- Strategically use color and texture

- Use typography to create hierarchy and clarity

- Make sure that the system communicates what's happening

- Think about the defaults
