    Exercise 2 DDL Insterting Data

    2026-02-04 11:10

    Tags: #ADV_DBMS Author: Duke Hsu

    Notes

    1. Table and Column Names

    2. For example, the table name is regions(lowercase) and the column name is REGION_ID (uppercase)

    3. SQL Statement Rules

    4. All SQL statements should be in uppercase.

    5. Each VALUES clause should be indented by one tab.

    6. When Inserting Data, Please Pay Attention to the Following:

    7. Check if the values referenced from the columns in the table are correct, if the data types match, and if the names are correct.
    8. Ensure that the referenced values in the table actually exist.
